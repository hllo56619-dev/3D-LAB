# Chemistry reaction library

The 3D Lab loads reaction rules from themed JavaScript modules for acid/base chemistry, precipitation, metals, gas evolution, redox/combustion, organic tests, thermal chemistry and oxides.

Recent audit modules:
- `16-audit-metals-halogen.js`, `16-audit-acid-redox.js` — reactive metals and halogens
- `17-audit-secondary-reactions.js` — secondary redox and complexes
- `18-audit-common-gaps.js` — ammonium, amphoteric oxides/hydroxides, peroxide and salt reactions
- `19-audit-reduction-ammonium.js` — oxide reduction and ammonium/base reactions
- `20-audit-industrial-gas.js` — methane, water-gas shift, Haber synthesis and thiosulfate/iodine
- `99-audit.js` — pair/triple coverage helpers

This is an evolving educational model, not a complete database of every reaction under every condition. A missing rule is not proof that no reaction occurs; new rules should have balanced equations and supported products.
